# 🐦 Tweetify

A simple **social posting platform** where users can register, log in, and create short posts (tweets).  
Built with **Node.js**, **Express**, **MongoDB**, and **JWT authentication**.

---

## 🚀 Features

- 🔐 User authentication with **JWT**
- 🧑‍💻 Register and log in users securely
- ✍️ Create, read, update, and delete short posts (tweets)
- ❤️ Like and unlike posts
- 📱 RESTful API design
- 🗄️ MongoDB database integration
- 🌐 Ready for frontend integration (React, Next.js, etc.)

---

## 🛠️ Tech Stack

| Technology | Description |
|-------------|-------------|
| **Node.js** | JavaScript runtime environment |
| **Express.js** | Web framework for Node.js |
| **MongoDB** | NoSQL database for storing user and post data |
| **Mongoose** | ODM library for MongoDB |
| **JWT (JSON Web Tokens)** | Secure authentication |
| **bcrypt.js** | Password hashing |
